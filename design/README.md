# Momoko 新版界面原型

- `project/*.dc.html`：全部页面原型，每个页面有 `XxxPC.dc.html`（1440 宽）和 `XxxMobile.dc.html`（390 宽）。
  文件是自定义模板语法的 HTML 源码，不能直接用浏览器打开；直接读文本：模板部分是布局，`renderVals()` 里的数据是页面要展示的信息。
  `Main.dc.html` 是六套配色总览，`canvas.json` 是画布上的画板排布与标题。
- `BRIEF.md`：原型的编写规范（配色令牌、组件类名、PC/手机外壳）。
- `IMPL_BRIEF.md`：前端实现规范（视觉规则、标签页、文案、后端修改方式、检查命令）。

原型来源：claude.ai 上的 Design 画布（导出于 2026-11-04，包含应用详情去掉控制台旁实例信息、文件编辑改弹窗与目录树可收起的修改）。
