托管模式
Momoko 在本机或任一节点上运行服务端（复用应用实例：控制台、文件、自启动、崩溃重启），适配器再提供专用设置表单、版本与资源更新、状态探测、备份回档；MGP 密钥由 Momoko 生成并写进服务端配置，接入即可用 GM。
仅 GM 模式
服务端部署在别处（另一台机器、容器、云主机），只填 MGP 地址和密钥。Momoko 不碰进程，只做状态监测、玩家查询、GM、运营配置和审计。之后随时可以改成托管。
统一接口 MGP v1
游戏服务端实现一组 HTTP 接口：manifest 声明能力、GM 指令及参数表单、查询视图和配置域；其余是 status、players、commands、catalogs、configs、assets、accounts、events。新游戏实现它就能接入，Momoko 前端不用改。
用户通行证 · 独立 server
Momoko 进程里另起一个 HTTP server（默认 :22634，可单独开关、绑定域名）。它只注册玩家路由：注册登录、OIDC、绑定、查看自己的数据、执行开放给玩家的 GM。管理接口在这个端口上根本不存在，两边的会话和令牌互不认。
