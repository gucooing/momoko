# 05 · 页型范式(Page Patterns)

> 每个业务页面都归入一个**页型**。`06-*` 的逐页规格只需写"用页型 X + 差异点",不重复描述通用结构。
> 组件名见 `03`/`03b`,移动端模式见 `02`(M-1…M-6)。

---

## P1 · 列表/CRUD 页(最主流)

**何时**:对一类实体做增删改查(用户、角色、实例、隧道、密钥、容器、镜像、任务…)。

**桌面结构(自上而下)**
1. `PageHeader`:标题 + 一句描述 + 右侧主操作(`新增`)。
2. `FilterBar`:横向筛选(搜索框 + 若干下拉/日期)+ `搜索`/`重置`。
3. `Toolbar`(可选):左=批量操作(选中后出现),右=视图切换/刷新/导出。
4. **主体**(二选一,判定见下):
   - **卡片流**:`EntityCard` 网格(`grid auto-fill minmax(300px,1fr)`)。
   - **表格**:`DataTable`(强列型)。
5. `Pagination`。
6. 表单弹窗:`FormDialog`(新增/编辑);删除用 `AdaptiveConfirm`。

**卡片 vs 表格 判定**
- **卡片**(优先,人性化):实体属性少、每条要"一眼看懂 + 就地操作"——用户、角色、实例、隧道、密钥、容器、镜像、文件源、OIDC 客户端。
- **表格**:强列、需跨行比较、列多且等宽——操作日志、任务、菜单树(树表)。
- 有条件时提供**视图切换**(卡/表),默认卡。

**状态**:加载=骨架(卡/行);空=`EmptyState`(带"新增"引导);错误=`ErrorState`(可重试);无权限=隐藏操作。

**移动**:见 `02` M-1 —— 表→卡强制、筛选折叠为底部 sheet、主操作用标题区/FAB、批量走底部操作条、分页简化。

---

## P2 · 详情页 / 只读概览

**何时**:查看单个实体的完整信息(实例详情、隧道统计、容器 stats)。

**结构**:`PageHeader`(标题=实体名 + 状态胶囊 + 操作)→ 若干 `AppPanel`(分区)→ 每区用 `DescriptionList`/`MetricStrip`/图表。移动单列堆叠。多为弹窗或抽屉承载(`*StatsDialog`)。

---

## P3 · 表单页 / 向导

**何时**:创建/编辑复杂对象、初始化向导、配置编辑(FrpcConfig、FrpsConfig、docker/config)。

**结构**:`FormDialog`(弹窗)或整页 `AppPanel` 内 `UForm`;字段分组用 `SectionHeader`;校验用 schema(`03b` §6)。
向导(初始化)= 顶部步骤条 + 一屏一步 + 吸底"下一步"。移动:见 `02` M-3(全屏、标签顶对齐、吸底)。

---

## P4 · 仪表盘 / 概览

**何时**:工作台。**结构**:安静问候 → `MetricStrip`(指标带,**非彩色 KPI 卡**)→ `AppPanel` 图表(ECharts)→ 次级模块(运行实例 `EntityCard` 流、快捷入口)。移动:见 `02` M-4(指标 4→2→1、图表堆叠)。

---

## P5 · 分析 / 监控(图表密集)

**何时**:`dashboard/analysis`、`dashboard/monitor`。**结构**:`PageHeader` + 响应式面板网格,每面板一图(ECharts)+ 标题/图例。移动单列。
> `dashboard/analysis` 是模板假数据页,**待决**(见 `08`):删除或改造为真实业务分析。

---

## P6 · 全屏工具页(终端 / 文件 / 控制台)

**何时**:`instance/console`、`openssh/terminal`、`instance/fileManager`、`file/index`。
**结构**:`meta.fullBleed`,无内容内边距;顶部极简工具条(路径/操作)+ 主体占满。终端=xterm 容器;文件=双栏(树+列表)桌面 / 单栏面包屑下钻移动(见 `02` M-2);编辑器=Monaco。
> **只换壳与工具条观感,保留终端/文件/编辑器的既有逻辑与数据流。**

---

## P7 · 认证 / 独立页(无外壳)

**何时**:`login`、`register`、`forgotPassword`、`initialize`、`public/*`、`oidc/authorize`。
**结构**:左/上品牌区(渐变,唯一允许大面积主色处)+ 右/下表单卡(`UForm`)。移动:品牌区收起,表单全宽居中。public 面向终端用户,移动优先、少 chrome。

---

## P8 · 异常页

**何时**:`exception/403`、`exception/404`、redirect。**结构**:居中 `EmptyState`/`ErrorState` 变体(大字/插画 + 说明 + 主操作)。移动全宽。

---

## 通用规则(所有页型)
- 页面根:`meta.fullBleed` 外的页面由 `AppContent` 给统一内边距/限宽;页面自身**不再包一层大卡**,直接用 `PageHeader` + 分区。
- 一屏第一焦点是**标题**,不是筛选或表格。
- 空/加载/错误三态**必须**实现,不留空白。
- 所有数字 tabular;所有超长文本省略;所有可点元素移动端 ≥44px。
