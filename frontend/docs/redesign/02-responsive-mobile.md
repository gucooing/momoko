# 02 · 响应式与移动端(Mobile is First-Class)

> 移动端不是"桌面缩一缩",也不是"能显示就行"。**每一页都必须单独设计移动端布局**,
> 在 `06-*` 的逐页规格里各自写明。本文件定义**全局断点、外壳移动端行为、各页型的移动端范式、
> 触控与手势、弹层/抽屉规范**——页面规格只需引用本文件的模式名。
>
> 注:本文出现的具体组件名以 `03b`(Nuxt UI)映射为准 —— 弹窗=`UModal`、抽屉/底部 sheet=`USlideover`、
> 分页=`UPagination`;文中若写 `el-*` 仅为语义示意。

---

## 1. 断点(Breakpoints)

统一使用以下断点(与 Tailwind 一致,便于 `sm: md: lg:` 前缀):

| 名称 | 宽度 | 典型设备 | 外壳形态 |
|---|---|---|---|
| `base` | < 640 | 手机竖屏 | 抽屉侧栏 + 单列 |
| `sm` | ≥ 640 | 大手机/竖屏平板 | 抽屉侧栏 + 1–2 列 |
| `md` | ≥ 768 | 平板竖屏 | 抽屉侧栏 + 2 列 |
| `lg` | ≥ 1024 | 平板横屏/小笔记本 | **固定侧栏出现** |
| `xl` | ≥ 1280 | 桌面 | 固定侧栏 + 多列 |
| `2xl` | ≥ 1600 | 大屏 | 内容居中限宽 |

**关键阈值 = `lg`(1024)**:`< lg` 为"移动/紧凑形态"(侧栏收进抽屉、表格转卡片、筛选折叠);`≥ lg` 为"桌面形态"。

> 现状 `menuStore.isMobile = width < 992`。**统一改为 `< 1024`(lg)**,并在 store 暴露语义化派生:
> `isMobile`(<768)、`isTablet`(768–1023)、`isCompact`(<1024,= 抽屉态)、`isDesktop`(≥1024)。
> 用 `@vueuse/core` 的 `useWindowSize`/`useBreakpoints`。页面里优先用 CSS 媒体查询/Tailwind 响应式类,
> 只有"结构级切换"(表↔卡、抽屉)才用 JS 判断。

## 2. 外壳移动端(Shell)

详见 `04-app-shell.md`,此处给移动端要点:

- **侧边栏**:`< lg` 收进**左侧离屏抽屉**(`el-drawer` 或自绘),由顶栏汉堡触发;点遮罩/选中项/滑动关闭;宽度 ~82vw(≤300px)。抽屉内是完整导航(分组、可展开)。
- **顶栏**:`< lg` 压缩为 `[☰ 汉堡] [页面标题(省略)] [溢出菜单 ⋯] [头像]`。搜索折叠为图标→点开为全宽输入/命令面板;次要图标(主题、语言、全屏、通知)收进"⋯"溢出菜单或用户抽屉。
- **标签栏(多开)**:`< lg` 默认**隐藏**(移动端不适合多标签);或退化为可横滑的小型标签条(仅在用户开启时)。
- **内容区**:内边距 16px;区块纵向间距 16px;一律单列或至多 2 列。
- **底部安全区**:`env(safe-area-inset-bottom)` 适配全面屏;固定操作条/FAB 需避让。

## 3. 各页型的移动端范式(被 06 引用)

### M-1 · 列表/CRUD 页(最常见)
- 桌面:PageHeader + FilterBar(横向) + 表格或卡片流 + 分页。
- 移动:
  - **表格 → 卡片列表**(强制)。每条记录一张 `EntityCard`:主标题 + 状态胶囊 + 2–4 行关键元信息 + 底部操作。次要列并入元信息或折叠进"详情"。
  - **FilterBar → 折叠筛选**:顶部一行"搜索框 + [筛选]按钮";点[筛选]弹出**底部 sheet**(`el-drawer direction=btt` 或弹层)放其余条件;已用筛选以 chips 展示、可一键清除。
  - **主操作(新增)**:置于 PageHeader(移动端标题右侧)或**右下 FAB**;批量操作在进入"多选模式"后出现**底部固定操作条**。
  - **分页**:简化为"上一页/下一页 + 第 x/y 页",或滚动加载(视数据量)。
  - 行内多操作 → 卡片底部"主操作按钮 + ⋯ 更多菜单"。

### M-2 · 详情/控制台页(终端、文件管理、实例控制台)
- 全屏、极简 chrome。移动:
  - 终端(xterm):适配容器宽度、开启软键盘工具条(常用键 Ctrl/Tab/方向/Esc);字号可调。
  - 文件管理:双栏(树+列表)→ 单栏 + 顶部**面包屑路径**下钻;操作走长按/更多菜单;上传用系统选择器。

### M-3 · 表单/向导(create 弹窗、初始化)
- 弹窗 `el-dialog`:`< lg` 变为**全屏或近全屏**(`fullscreen` 或 `width:100%` + 顶部返回);表单标签改为**顶部对齐**(`label-position=top`),控件占满宽;底部操作**固定吸底**。
- 多步向导(初始化):步骤条移到顶部为**紧凑点状/编号**;一屏一步;下一步吸底。

### M-4 · 仪表盘/分析/监控
- 指标带:4 列 → 2 列 → 1 列(hairline 分隔方向随之变横为纵)。
- 图表:降采样/减少刻度,单列堆叠,固定高度可滑动查看;图例移到图下方可折叠。
- 次要模块(快捷入口、运行实例)单列堆叠。

### M-5 · 认证/独立页(登录、注册、找回、public/*、OIDC)
- 品牌区(左/上)`< md` **隐藏或压成顶部小标识**;表单卡片全宽、居中、留白;字段大号触控友好。
- public 分享/统计页:面向终端用户,移动优先,单列,少 chrome。

### M-6 · 异常页(403/404)
- 居中插画/大字 + 说明 + 主操作按钮;移动端图缩小,按钮全宽。

## 4. 触控与可访问性

- **触控目标 ≥ 44×44px**;可点区不要只有图标像素大小,加内边距。
- 列表项、卡片整体可点时给足 hover/active 反馈(移动端用 `:active`)。
- 悬浮态信息(tooltip、hover 显示的操作)在触控端要有**常驻或点击**的等价路径(不能只靠 hover)。
- 焦点可见(`:focus-visible` 主色环);表单错误有文字说明,不只靠颜色。
- 对比度:正文 ≥ 4.5:1,大字/图标 ≥ 3:1(中性色阶已按此校准)。

## 5. 弹层/抽屉/菜单规范

| 元素 | 桌面 | 移动(< lg) |
|---|---|---|
| 表单弹窗 `el-dialog` | 居中,宽 480–720 | 全屏/近全屏,吸底操作 |
| 侧栏抽屉 | —(固定侧栏) | 左侧离屏抽屉 |
| 筛选/次操作 | 行内/下拉 | 底部 sheet(`direction=btt`) |
| 行内更多操作 | hover 显示/文字按钮组 | "⋯" 触发底部菜单 |
| 确认框 `Popconfirm` | 就近气泡 | 居中小弹窗或底部 sheet(用 `AdaptiveConfirm`) |
| 通知/用户菜单 | 下拉 | 抽屉或全屏面板 |

> 现有 `AdaptiveConfirm`、`FilePager`、`BadgeTabsMenu` 等已考虑移动;重写时沿用其"自适应"思路并纳入本规范。

## 6. 移动端验收清单(每页必过)

- [ ] 390×844(手机)与 768×1024(平板)截图无破版、无横向溢出。
- [ ] 表格已转卡片;筛选已折叠;主操作可达(FAB/吸底/标题区)。
- [ ] 弹窗/抽屉全屏或吸底,表单标签顶对齐,操作吸底。
- [ ] 所有可点元素 ≥44px;hover-only 信息有触控等价。
- [ ] 文本省略正确,无溢出;安全区适配。
- [ ] 明/暗两态在移动端都正确。
